WeatherLog2 サポート

WeatherLog2に関するご質問や不具合のご連絡は、共通のサポートメールで受け付けています。

support.yukiapps@gmail.com

対象：WeatherLog2 1.0.0 / iPhone

お問い合わせ時のお願い

アプリのバージョン、iOSのバージョン、発生した内容、再現手順をご記載ください。必要に応じてスクリーンショットも添付してください。OpenWeather APIキーは送信しないでください。

天気を利用するまでの流れ

  1. OpenWeatherのアカウントを作成します。
  2. 同じアカウントでOne Call API 3.0を有効化します。
  3. WeatherLog2の設定からWeather / OpenWeatherを開きます。
  4. APIキーを保存し、位置情報の利用を許可します。

料金、無料利用枠、日次上限などはOpenWeatherの最新情報をご確認ください。yukiappsはOpenWeatherの契約や課金を管理しません。

天気が更新されないとき

  • One Call API 3.0が同じOpenWeatherアカウントで有効になっているか確認してください。
  • アカウントのリクエスト上限をご確認ください。
  • iPhoneの設定で位置情報の利用が許可されているか確認してください。
  • WeatherLog2の設定画面から更新操作をお試しください。

写真とカレンダーについて

写真とカレンダーの利用は任意です。権限はiPhoneの設定からいつでも変更できます。WeatherLog2は読み取りに利用し、写真や予定の編集・削除は行いません。

プライバシー

位置情報、OpenWeather、写真、カレンダー、端末内保存データの扱いは、WeatherLog2 プライバシーポリシーをご確認ください。

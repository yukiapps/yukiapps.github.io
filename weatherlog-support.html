WeatherLog サポート

WeatherLogに関するご質問や不具合のご連絡は、共通のサポートメールで受け付けています。

support.yukiapps@gmail.com

対象：WeatherLog 1.0.0 / iPhone

お問い合わせ時のお願い

アプリのバージョン、iOSのバージョン、発生した内容、再現手順をご記載ください。必要に応じてスクリーンショットも添付してください。OpenWeather APIキーは送信しないでください。

最初に必要な設定

  1. OpenWeatherのアカウントを作成し、APIキーを取得します。
  2. 同じアカウントでOne Call API 3.0を有効化します。
  3. WeatherLogで記録地点と、記録先のカレンダーを設定します。
  4. APIキーを保存し、最初の記録をお試しください。

料金、無料利用枠、リクエスト上限などはOpenWeatherの最新情報をご確認ください。yukiappsはOpenWeatherの契約や課金を管理しません。

毎朝6時の自動記録

アプリ内の案内に沿って、Appleのショートカットで個人用オートメーションを設定してください。設定後は、前日の天気を毎朝6時に記録します。自動記録が動かない場合は、ショートカットのオートメーションが有効になっているか確認してください。

記録できないとき

  • One Call API 3.0が同じOpenWeatherアカウントで有効になっているか確認してください。
  • APIキー、通信状態、OpenWeatherのリクエスト上限をご確認ください。
  • iPhoneの設定でWeatherLogのカレンダー利用が許可されているか確認してください。
  • 記録地点と記録先カレンダーが選択されているか確認してください。

同じ日を再度記録した場合

WeatherLogが作成した同じ日の記録がある場合は、新しい予定を重複して追加せず、既存の記録を更新します。

プライバシー

位置情報、OpenWeather、APIキー、カレンダー、端末内保存データの取り扱いは、WeatherLog プライバシーポリシーをご確認ください。
